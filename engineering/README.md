# Engineering

Dragun's engineering work spans software, deployment, infrastructure, and physical prototypes.

- `physical/` — physical designs and the shared character evolution sketch. Each prototype has its own mechanical, electrical, bill of materials, and validation files; see [physical](physical/README.md) and the [egg](physical/prototypes/egg/README.md).
- `services/` — application services.
- `workloads/` — application workloads.
- `deploy/` — deployment charts and environment configuration.
- `infrastructure/` — infrastructure tooling and configuration, including [Terraform](infrastructure/terraform/README.md) and Minikube.
- `Makefile` — engineering entry points.
